# Wagner Feedmill Website

Next.js 14 website for Wagner Feedmill & Silo Plants GmbH with DE/EN/RU support.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Hero Video

Place your hero video at `public/images/hero.mp4`. Until then, the poster image (`Projektierung.webp`) is shown when the video is missing.

## Environment

Optional: `SITE_URL=https://wagner-feedmill.de` for sitemap generation.
